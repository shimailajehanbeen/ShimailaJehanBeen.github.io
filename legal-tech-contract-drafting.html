Legal Tech – Contract Drafting & Version Control

A legal-tech portfolio project exploring how contracts can be drafted, managed, and tracked using GitHub.

Introduction

Contract drafting is a core part of legal practice, yet it is often handled through static documents such as Word files or PDFs. These formats make it difficult to track changes, manage versions, and collaborate efficiently.

This project explores how tools commonly used in technology — specifically GitHub — can be applied to legal contract management in a structured and transparent way.

Problem Statement

Traditional contract drafting faces several challenges:

  • Lack of clear version history
  • Difficulty tracking clause-level changes
  • Limited collaboration and accountability
  • Risk of using outdated contract versions

What I Did

In this project, I:

  • Drafted a sample service agreement for portfolio purposes
  • Organised the contract into clearly defined clauses
  • Used GitHub to track revisions and changes over time
  • Documented clause updates to demonstrate version control

Tools & Skills Used

  • Contract drafting
  • Legal documentation
  • GitHub
  • Version control concepts
  • Legal technology fundamentals

Outcome & Learning

This project demonstrates how legal documents can be treated as living documents rather than static files. It highlights the potential of legal technology to improve transparency, accuracy, and efficiency in contract management.

Through this project, I gained practical exposure to how technology can complement legal workflows, particularly in contract-heavy roles.
